Test des liens dans Safari

Cliquez sur chaque bouton, l'un après l'autre, avec un clic gauche normal. Notez pour chacun si le site de l'EAE s'ouvre dans un nouvel onglet, dans cet onglet ou pas du tout.

  1. A · Lien ordinaireUn lien classique, dans une page normale.Ouvrir le site (A)
  2. B · Page réécrite (comme le carnet aujourd'hui)Le bouton affiche d'abord une page réécrite ; cliquez ensuite sur le lien qu'elle contient.Préparer le test B
  3. C · Page affichée sans réécritureLe bouton affiche d'abord une page construite autrement ; cliquez ensuite sur le lien qu'elle contient.Préparer le test C
  4. D · Ouverture demandée par le scriptLe script demande au navigateur d'ouvrir un nouvel onglet.

Ensuite, dites-moi simplement : A, B, C, D → nouvel onglet / même onglet / rien.
